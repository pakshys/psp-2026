# Proposal

## Title
**GLAMMorous exchange**

## Description
**GLAMMorous exchange** - A stock exchange app that lets users track stocks, view prices and charts, manage their portfolio, and monitor market performance. Users can search for companies, view stock details, follow price changes, and buy or sell stocks through an interface.

## Key features

### Transaction security and efficiency
- Secure and fair order execution
- Order validation

### Trades 
- Make Market/Limit/Stop orders
- View Margin, ROI
- View Order book
- Order matching proccess

### Portfolio
- View pending buy/sell orders
- Manage pending buy/sell orders
- View open position
